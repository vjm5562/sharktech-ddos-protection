## 一、先搞清楚：你到底需要多大的防护

防护能力这件事，要看你业务的"被攻击概率"和"被攻击规模"。一般来说：

- **个人博客、小型展示站**：基本不会被盯上，1-5Gbps的防护就够用，普通云服务器自带的免费防护都行。
- **中小型游戏服务器、论坛、社区**：这是重灾区，3-10Gbps的攻击很常见，建议至少20Gbps起步。
- **中大型游戏、电商促销、金融类业务**：攻击动辄几十G，50Gbps以上的防护才心里有底。
- **头部游戏、支付、交易所**：百G甚至T级攻击都见过，需要可弹性扩展的清洗能力。
